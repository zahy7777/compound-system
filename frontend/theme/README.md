# 外观主题

主题拥有本机外观偏好、主题资产、文字纸面与点击反馈。工作区仍拥有布局、DOM、草稿和交互；主题不认识业务对象、不发业务请求。入口 `main.js` 装配主题，`main.css` 在布局样式之后引入主题。

```text
theme/
├─ index.js / settings.js / feedback.js  偏好、外观窗口、点击反馈
├─ default/style.css                    原有外观完整抽取
├─ persona/                             异闻录皮肤、人物拼贴与纸纹
├─ paper/index.js                       根据装饰插槽尺寸生成稳定 SVG 毛边
└─ assets/                              构建输出的只读图片，勿手工编辑
```

组件用 `data-paper` 暴露装饰插槽，用 `data-visual-key` 提供不透明视觉身份。视觉分三层：body 壁纸、共用颜色底板、完整工作区内容。底板按插槽实际位置生成向外扩散的撕纸色块，颜色直接复用控件主题色，整块纸面和碎片完全不透明，蒙版只包含实心轮廓，不使用透明渐变、模糊或边缘羽化；带不规则缺口与散落碎片；允许相邻色块重叠，所有文字和按钮统一在它上方。按钮透明且无独立边框，装饰 `pointer-events:none`，不扩大点击范围或占用布局。原生弹窗与登录卡片各有自己的底板，保持相同层次。

异闻录层级配色：区域标题统一深蓝底/冰蓝字；根事项金色、下级事项淡紫；正文保持纸白。闭环页签按不透明视觉身份计算独立色相，同身份稳定，正文不继承页签颜色；默认主题色相与外框保持原样。

主题只观察插槽的尺寸、增删、滚动与悬浮，不读取业务对象，不因计时文本更新持续重绘。轮廓按稳定身份和尺寸确定，48 种变化与最多 512 条缓存。只显示进入视口的色块；滚动与尺寸变化在动画帧中合并更新。换主题断开观察并删除全部底板。

本机 `localStorage` 的 `compound:appearance` 保存主题、动效、音效与音量；不进入 SQLite、event 或备份。默认主题不请求人物图。点击音效默认关闭，启用后使用 Web Audio 生成短促反馈；系统减少动态效果优先。弹窗内动效放在弹窗顶层，装饰不截获操作。存储失败在外观窗口明确提示。

添加主题只需增加主题目录与受 `data-theme` 限定的样式，在偏好校验和主题选项登记名称；沿用现有装饰插槽。禁止主题修改布局尺寸、业务流程或复制组件。PNG 由 esbuild 输出带内容散列的文件名，避免多主题同名资产冲突；服务仅为 `/theme/assets/` 提供静态读取，业务认证保持原规则。

验证：`tests/browser/theme.spec.js` 覆盖切换与多窗口同步、默认主题不下载艺术资产、600 条事项、长正文/窄屏、开关/键盘动效、真实 Web Audio 音效及故障重试。`COMPOUND_TEST_THEME=persona` 将同一套完整用户流程在异闻录主题运行，包括真实 Electron 与前缀代理手机登录。AI 参考图与最终截图的逐屏对照保存在本 worktree 的 `.run/theme-acceptance/`。
